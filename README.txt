PHILIPPINES' BEST COFFEE - PHP + MYSQL PROJECT

REQUIREMENTS
- XAMPP with Apache, MySQL, PHP, and phpMyAdmin
- A web browser
- Internet connection for Bootstrap, jQuery, Google Fonts, and remote product images

DATABASE
- For a new installation, import database.sql in phpMyAdmin.
- For an existing installation, import database_update_products.sql to add the products
  from the Coffee, Iced Coffee, and Pastries asset folders. The update can be run again
  without adding duplicate products.
